EKF SLAM (slam-factory)

Robotics · SLAM · 2026 – present · personal project
Python · ROS 2 · NumPy

A framework rather than a script: abstract base classes for the motion model, the measurement model and the data association step, so a different filter can be dropped in without touching the plumbing around it.

The core is plain Python and NumPy and knows nothing about ROS. The ROS 2 wrapper is deliberately thin — it converts messages and nothing else — which means the filter can be exercised at full speed from a test file instead of from a simulator.

A 25-test suite covers prediction, update and data association separately, because in a filter these fail in ways that look identical from the outside. Written following Thrun, Burgard and Fox, Probabilistic Robotics.
