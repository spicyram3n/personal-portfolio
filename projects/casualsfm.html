casualSfM

Vision · 2025 · personal project
Python · OpenCV · NumPy

Two photographs of the same scene, and out the other end a coloured 3D point cloud. Every stage is written out by hand rather than handed to a library: SIFT extraction and ratio-test matching, a normalised 8-point algorithm wrapped in RANSAC for the fundamental matrix, the essential matrix and pose recovery with a cheirality check, DLT triangulation, then bundle adjustment.

On the test pair it recovers 701 points at 0.50 px mean reprojection error, which is to say the estimated geometry explains the original observations to well under a pixel.

The point was never the point cloud. It was to understand where each of these steps fails and why, which is why the whole thing is written up chapter by chapter with the maths set beside the code that implements it.

  • Github repository. The source, the four stages as independent modules, and the evaluation scripts.
  • The build log. Four chapters taking the pipeline apart: features, the fundamental matrix, triangulation, and evaluation.
